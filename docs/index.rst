cqlib-vqe 文档
==============

``cqlib-vqe`` 是面向 cqlib 2.x 的分子电子结构 VQE 软件包，提供分子哈密顿量预处理、
规范单重态 UCCSD 线路、Jordan--Wigner / Bravyi--Kitaev / parity 映射、全算符池自适应
选择、本地态矢量执行，以及天衍云端测量支持。
